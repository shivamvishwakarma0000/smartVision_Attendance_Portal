# SmartVision Portal 🚀

An advanced attendance management portal using Face Recognition and modern Glassmorphism UI.

## Local Development

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```
